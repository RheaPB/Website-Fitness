# Fitness Revolution Website

## Overview

Fitness Revolution is a web-based platform designed to support the management and operation of a fitness centre. The system provides features for administrators, visitors, and registered members, while also including an online store for fitness-related products.

## Features

### Administrator

* View and manage member profiles
* Create, edit, and delete membership plans
* Manage gym classes and schedules
* Add and manage trainers
* Assign trainers to classes
* Manage client reviews
* Generate membership, attendance, and financial reports

### Visitor

* View the gym landing page and information
* Browse current promotions and special offers
* Explore the online shop
* Search and filter products
* Manage a shopping cart
* Create a user account
* View gym classes, facilities, trainers, and events
* Access contact information

### Member

* Log in and manage personal information
* View payment and cart history
* Book fitness classes
* Reorder previous purchases
* Cancel pending orders
* Write gym reviews
* Renew, cancel, or upgrade memberships
* Access visitor features

## Key Requirements

The platform is designed with performance, data security, and reliability in mind. Sensitive information such as passwords and payment details should be protected using industry-standard encryption methods, while the system is intended to provide continuous access.
